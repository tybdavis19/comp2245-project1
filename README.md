Fresh Roots Market

Project Description

Fresh Roots Market is a landing page designed to showcase fresh produce and provide visitors with information about the market.

The website includes information about the market, its features, visiting details, and a mailing-list form where visitors can sign up for updates.

Features:

Navigation header

Hero section introducing Fresh Roots Market

Features section highlighting the market

Visiting information and the opening hours

Customer testimonials

Mailing-list subscription form with JavaScript validation

Responsive design for desktop and mobile devices

Technologies Used:
HTML5
CSS3
JavaScript
Git and GitHub

Project Structure

index.html – Website structure and content

styles.css – Website styling and responsive layout

app.js – Mailing-list form validation

images/ – Website images
